# 计算 04 · 图书数据采集规范

> 推荐系统背后的书库：**约 300 本**（可以扩充到 500 本）适合小学中高年级到初一的图书。
> **当前进度**：v0.1 已完成 301 本，自检 0 错误 0 警告，待教师审核。见 [书库/README.md](书库/README.md)。
> 存储形式：JSON 文件（`books.json`），服务器启动时读进内存，不用数据库。正式开发时复制到 `app/content/jisuan/`。

---

## 1. 原则

1. **都是真书**：书名、作者必须真实存在，并且可以核实。不编书。
2. **适龄**：以六年级为中心，覆盖四年级到初一。内容健康，不收恐怖、暴力、早恋题材，也不收成人向的读物。
3. **简介自己写**：60–100 字。不复制出版社文案、网店介绍或书评网站的文字（版权）。不剧透结局。
4. **标签准**：标签决定推荐质量。每本书的标签都要有人核对过。
5. **分布均衡**：每个大类、每个标签都要有足够的书，算法才有得挑（第 4 节）。
6. **不用封面图片**：封面由前端根据大类生成（第 3 节），不采集封面。

## 2. 字段

```json
{
  "id": "b0123",
  "title": "海底两万里",
  "author": "儒勒·凡尔纳",
  "origin": "外国",
  "category": "科幻未来",
  "topic": ["冒险", "海洋", "科幻"],
  "tone": ["紧张刺激", "想象力"],
  "form": "小说",
  "length": "长",
  "grade": "5-7",
  "hook": "坐上潜水艇，去海底周游世界",
  "summary": "（60–100 字，自己写，不剧透结局）",
  "anchor": true,
  "series": "",
  "q": 1.0,
  "source": ["教育部阅读指导目录2020"],
  "in_library": null,
  "shelf": ""
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | `b` + 4 位数字，确定后不再改（回放包和日志都靠它） |
| `title` | 是 | 不带书名号。系列书收第一本，写全名，例如“哈利·波特与魔法石” |
| `author` | 是 | 外国作者用通行的中文译名 |
| `origin` | 是 | `中国` / `外国` |
| `category` | 是 | 12 个大类之一（第 3.1 节） |
| `topic` | 是 | 2–4 个题材标签（第 3.2 节） |
| `tone` | 是 | 1–2 个风格标签（第 3.3 节） |
| `form` | 是 | 体裁（第 3.4 节） |
| `length` | 是 | `短`（约 5 万字以内，或绘本、漫画单册）/ `中` / `长`（约 15 万字以上） |
| `grade` | 是 | 适合的年级段，例如 `4-6`、`5-7` |
| `hook` | 是 | 一句话吸引语，≤18 字，写给小学生看 |
| `summary` | 是 | 简介，60–100 字 |
| `anchor` | 是 | 是否可以做第 1 轮的“摸底书”：知名度高、标签鲜明。每个大类至少 4 本 |
| `series` | 否 | 同一系列的书写同一个系列名。出题和推荐时，同一系列最多 1–2 本 |
| `q` | 是 | 口碑分 0–1，按来源取最高（第 5 节） |
| `source` | 是 | 来源书目的名称（可以有多个） |
| `in_library` | 否 | 学校图书馆是否有这本书。`null` 表示未核对 |
| `shelf` | 否 | 馆内位置，例如“三楼 I 类”。有的话，推荐卡上会显示“去图书馆三楼 I 类书架借” |

## 4. 数量与分布

以 300 本为例（`build_books.py` 按下表检查）：

| 维度 | 要求 |
|---|---|
| 每个大类 | 20–45 本 |
| 每个题材标签 | ≥ 8 本 |
| 每个风格标签 | ≥ 20 本 |
| 每个大类 | 至少有 2 种风格、每种 ≥ 3 本（第 2–3 轮出“风格对照题”要用） |
| 热门题材（冒险、动物、科学、魔法奇幻、侦探推理、校园生活） | 至少 2 种体裁、每种 ≥ 3 本（第 4 轮出“体裁对照题”要用） |
| 体裁比例 | 小说约 45%，童话寓言约 12%，科普约 18%，漫画绘本约 8%，传记约 8%，诗文散文约 9% |
| 中外比例 | 中国约 55%，外国约 45% |
| 年级段 | 以五、六年级为主（约 60%）；偏易的（三、四年级）和偏难的（初一）各约 20% |
| 篇幅 | 短、中、长大致各占三分之一 |
| `anchor` | 每个大类 ≥ 4 本 |

## 5. 来源与口碑分 `q`

| 来源 | `q` | 说明 |
|---|---|---|
| 教育部《中小学生阅读指导目录（2020 年版）》小学段、初中段 | 1.0 | 主干 |
| 统编语文教材“快乐读书吧”推荐书目（一至六年级） | 0.9 | 学生熟悉，适合做 `anchor` |
| 国内重要儿童文学奖获奖作品：全国优秀儿童文学奖、冰心儿童文学奖等 | 0.8 | 补充中国当代作品 |
| 国际儿童文学奖获奖作品的中文版：国际安徒生奖作家作品、纽伯瑞奖等 | 0.8 | 补充外国作品 |
| 权威机构的科普推荐书目：中国科普作家协会、国家图书馆少儿馆推荐等 | 0.8 | 补足科学探索类 |
| 其他公开的分级阅读书目、学校图书馆的借阅热榜 | 0.6 | 补缺 |

- 每本书至少有 1 个来源，写进 `source`。
- `sources.md` 记录每个来源的名称、版本年份、获取的网页或文件，便于核查。
- **学校图书馆书目**如果能拿到（书名、作者、ISBN 或馆藏号），就逐本核对并填 `in_library` 和 `shelf`。之后可以打开配置 `prefer_in_library`：在馆的书打分时加 `+0.05`。

## 6. 采集流程

| 步骤 | 做什么 | 谁做 | 产出 |
|---|---|---|---|
| 1 列书单 | 从第 5 节来源汇总书名和作者，去重（同书不同译名、同系列多本） | 开发者，可借助 AI 整理；把握不大的条目标出，留给审核 | `书库/草稿/*.txt` |
| 2 初标 | 按第 3 节给每本书打大类、题材、风格、体裁、篇幅、年级段 | 开发者，可借助 AI 初标 | 同上 |
| 3 写简介 | 每本写 `hook` 和 `summary`。可以用 AI 起草，但必须是自己的表述，并且核对内容事实 | 开发者 | 同上 |
| 4 跑自检 | `python3 build_books.py`（开发后改为 `yxz check books`）检查字段和分布；不达标就补书或调整标签 | 开发者 | `check_report.md` |
| 5 审核 | 教师用 `books_review.csv` 抽查至少 20%：标签准不准、简介有没有错、适不适合六年级。有疑问的整本删除 | 授课教师 | 审核记录 |
| 6 定稿 | 分配正式 `id`，冻结 | 开发者 | `books.json` v1.0 |

**审核重点**
- 简介里有没有剧透、有没有事实错误（人物、情节对不上）。
- 有没有不适合小学生的内容。“战争与和平”类的书只收教育部目录里有的。
- 同一作者的书不超过 6 本，避免推荐结果“扎堆”。

## 7. 自检：`yxz check books`

| 检查 | 不通过就 |
|---|---|
| 字段齐全，标签都在 `tags.json` 里 | 报错，拒绝启动 |
| `id` 唯一；“书名 + 作者”唯一 | 报错 |
| `hook` ≤ 18 字；`summary` 60–100 字 | 报错 |
| 题材 2–4 个，风格 1–2 个 | 报错 |
| 第 4 节的各项分布 | 警告，并列出缺多少本 |
| 简介里出现敏感词表中的词 | 报错 |
| 简介和其他书的简介相似度过高（疑似模板化） | 警告 |

自检报告输出到 `/data/check/books.md`：各大类、标签、体裁的数量表，以及缺口清单。
